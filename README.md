# 系列组织

> 组织系列、续作与番外，保留每部作品独立的身份、修订和人物解释。

## 简介

河图洛书专业插件。分别确认作品范围 → 登记固定成员引用 → 组织阅读顺序与续作关系 → 对照角色出演 → 准备番外 → 仅向目标作品交接。

## 快速上手

在河图安装启用后，向 Codex 说明创作目标。Codex 经河图 CLI/MCP 发现包内 Skill，读取固定作品和已有成果；作者回到专业工作面阅读、比较与反馈。

开发环境为 Node.js 25、npm。

```bash
npm ci
npm run build
npm run verify
npm run package
```

## 边界

专业状态由本包维护，正文、正式设定、候选、采纳和定稿由宿主维护。生成、翻译及声音制作使用作者选择的外部 Agent 或工具；联网、外发及付费由实际操作另行决定。

## 协作方式

[功能清单](CAPABILITIES.md)用于能力发现，[开发文档](docs/README.md)维护产品、领域、合同、用例与验收。接口参数以包内 manifest 和当前安装版发现为准。
